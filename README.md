## 📦 Installation

<div class="installation-container" style="background-color: #f8f9fa; border-radius: 10px; padding: 20px; margin: 20px 0;">
  <div class="installation-step" style="margin-bottom: 20px;">
    <h3 style="margin-bottom: 10px;">📥 Step 1: Clone the Repository</h3>
    <div style="background-color: #282c34; border-radius: 5px; padding: 15px; color: #ffffff;">
      <code>git clone https://github.com/Nirajd071/discussync.git</code><br>
      <code>cd discussync</code>
    </div>
  </div>

  <div class="installation-step" style="margin-bottom: 20px;">
    <h3 style="margin-bottom: 10px;">🔧 Step 2: Set Up the Frontend</h3>
    <div style="background-color: #282c34; border-radius: 5px; padding: 15px; color: #ffffff;">
      <code>cd frontend</code><br>
      <code>npm install</code>
    </div>
  </div>

  <div class="installation-step" style="margin-bottom: 20px;">
    <h3 style="margin-bottom: 10px;">⚙️ Step 3: Set Up the Backend</h3>
    <div style="background-color: #282c34; border-radius: 5px; padding: 15px; color: #ffffff;">
      <code>cd ../backend</code><br>
      <code>python -m venv venv</code><br>
      <code>source venv/bin/activate  # On Windows: venv\Scripts\activate</code><br>
      <code>pip install -r requirements.txt</code>
    </div>
  </div>

  <div class="installation-step">
    <h3 style="margin-bottom: 10px;">🚀 Step 4: Start the Application</h3>
    <div style="background-color: #282c34; border-radius: 5px; padding: 15px; color: #ffffff;">
      <code>cd ..</code><br>
      <code>chmod +x start_servers.sh</code><br>
      <code>./start_servers.sh</code>
    </div>
    <p style="margin-top: 10px; font-style: italic;">This script will start both the frontend and backend servers.</p>
  </div>
</div>
